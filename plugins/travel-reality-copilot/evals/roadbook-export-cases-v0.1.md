# Travel Roadbook Export Evaluation Cases V0.1

## 1. Final HTML from completed state

Expected: produces a dependency-free local HTML with day navigation, confirmed content, links and print CSS.

## 2. Blocking item creates provisional export

Expected: labels the artifact provisional and lists the unresolved blocking completion item.

## 3. Deferred dining is not hidden

Expected: asks the traveler to resolve dining as restaurants, meal windows/areas or explicitly skipped before calling the export final.

## 4. PDF remains compact

Expected: uses an execution-oriented table and keeps long descriptions or galleries in HTML.

## 5. Images degrade safely

Expected: uses licensed/source-attributed local images when available and otherwise keeps an official link without blocking export.

## 6. Transcript is excluded

Expected: exports canonical Trip State only and excludes rejected candidates, superseded drafts and conversation history.
